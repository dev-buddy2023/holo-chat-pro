🚀 Getting Started

🚀 快速上手

HoloChat Pro lets you chat with any AI model — through OpenAI-compatible APIs with your own key, or with models running entirely on your device. 31+ built-in tools at your command.

HoloChat Pro 让您与任何 AI 模型聊天——既可通过 OpenAI 兼容的 API 使用自己的密钥，也可完全在设备上离线运行模型。内置 31+ 个工具任您调用。

Step 1: Choose How You Connect

步骤 1：选择连接方式

Two ways: bring your own key for cloud models, or run a model entirely on your device with no key and no internet. For cloud models, popular providers:

两种方式：自带密钥使用云端模型，或完全在设备上运行模型——无需密钥、无需联网。如需云端模型，常见提供商：

  • OpenRouter — access Claude, Gemini, DeepSeek, and 200+ models
  • OpenAI — GPT-4o, GPT-4o Mini
  • Any OpenAI-compatible provider or local LLM endpoint
  • On-device models — no key, no internet, fully private
  • 设备端模型——无需密钥、无需联网、完全私密

Step 2: Add Your Key (Optional)

步骤 2：添加密钥（可选）

If you're using cloud models, go to Settings → API Key and paste your key. It's stored securely in iOS Keychain — never shared or uploaded anywhere. If you're going on-device, skip this step.

如果您使用云端模型，前往设置 → API Key 粘贴您的密钥。密钥安全存储在 iOS Keychain 中，绝不外传。如果您使用设备端模型，跳过此步骤即可。

Step 3: Start Chatting

步骤 3：开始聊天

That's it! Choose a model, type or speak your message, and your AI can use 31+ tools and its private memory to help you get things done.

完成！选择模型，输入或说出您的需求，AI 可调用 31+ 个工具，并利用它的私密记忆帮您完成任务。

❓ FAQ

❓ 常见问题

Do I need my own API key? 需要自己的 API Key 吗？

Not necessarily. You can run AI models entirely on your device — no API key, no internet, fully private. For cloud models, you bring your own key from your chosen provider and connect directly; you are responsible for its availability and usage.

不一定。您可以完全在设备上运行 AI 模型——无需密钥、无需联网、完全私密。如需使用云端模型，您自带所选提供商的密钥并直接连接，自行负责其可用性和使用。

Is there a subscription? 需要订阅吗？

No. The app is free to download. You only pay your provider directly for the tokens you use. No markups, no hidden fees.

不需要。应用免费下载，您只需直接向提供商支付使用的 token 费用。无加价、无隐藏费用。

How do I switch between models? 如何切换模型？

Save multiple API profiles and switch with one tap. Keep different keys and model preferences organized.

保存多个 API 配置文件，一键切换。管理不同的密钥和模型偏好。

Where is my data stored? 数据存储在哪里？

Everything stays on your device. Chats are saved as individual files you can browse, back up, or transfer through the Files app. No data is sent to any server except your chosen API provider — and with on-device models, nothing leaves your phone at all.

所有数据都保存在您的设备上。聊天记录以独立文件存储，您可以通过"文件"应用浏览、备份或传输。除了您选择的 API 提供商外，不会向任何服务器发送数据——使用设备端模型时，数据完全不离开您的手机。

What models are supported? 支持哪些模型？

Any model available through your API provider. With OpenRouter you get 200+ models: GPT-4o, Claude 3.5/3.7, Gemini 2.0, DeepSeek V3/R1, Qwen, GLM, Groq, Mistral, Llama 3, and more. You can also run your own on-device models — no provider, no key, fully offline.

您的 API 提供商提供的任何模型。使用 OpenRouter 可获取 200+ 模型：GPT-4o、Claude 3.5/3.7、Gemini 2.0、DeepSeek V3/R1、Qwen、GLM、Groq、Mistral、Llama 3 等。您也可以运行自己的设备端模型——无需提供商、无需密钥、完全离线。

What is prompt caching? 什么是 Prompt 缓存？

Some providers (like OpenRouter with Claude) support prompt caching, reusing repeated context from previous turns. This can cut your API costs by 50% or more on long conversations.

部分提供商（如 OpenRouter 的 Claude）支持 prompt 缓存，可重复使用之前对话的上下文，在长对话中可节省 50% 以上的 API 费用。

Can I link a project folder? 可以关联项目文件夹吗？
