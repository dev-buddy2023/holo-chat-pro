OpenRouter Setup

Bring your own key — HoloChat Pro does not provide any API service.

Bring your own key

HoloChat Pro is a client, not a model provider. You add your own OpenRouter API key, and the app connects you to the models you already have access to. There is no subscription in this app — you pay OpenRouter directly for the tokens you use, at their prices.

Setup

  1. Create an API key at openrouter.ai/keys.
  2. In the app, add a new API profile and paste the key. The base URL is https://openrouter.ai/api/v1.
  3. Pick a model and start a conversation. Profiles can be saved and switched with one tap, so you can move between OpenRouter, OpenAI, and any OpenAI-compatible provider without reconfiguring.

Model browser

The built-in model browser lists OpenRouter models with filters for Tools, Reasoning, Structured Outputs, and Vision, plus warnings for models that are being deprecated. Tool calling is what makes the 31+ built-in tools work, so check the Tools filter before switching models.

How requests are attributed

Requests sent by the app include attribution headers, so usage is credited to the app's public page on OpenRouter:

HTTP-Referer: https://dev-buddy2023.github.io/holo-chat-pro/
X-OpenRouter-Title: HoloChat Pro
X-OpenRouter-Categories: general-chat,personal-agent

The app page is live at openrouter.ai/apps/url/…. Categories are merged over time, and only values from OpenRouter's recognised list are accepted — general-chat and personal-agent are the ones this app uses.

Notes

  • The app stores conversations as files on your device. No accounts, no cloud sync, no telemetry.
  • Nothing is sent to OpenRouter unless you send a message in a conversation using an OpenRouter profile.
  • On-device models run locally and send no network requests at all.
